# RISC-V--ALU-with-CONTROL-UNIT
Designed a 32-bit RISC-V ALU with an instruction-based Control Unit using Verilog and Vivado. Supports ADD, SUB, AND, OR, XOR, SLL, SRL, SRA, SLT and SLTU operations. Verified functionality through behavioral simulation and analyzed the synthesized hardware for resource utilization and timing.
